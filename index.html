Sentence to vectors
The dog token is position four

Explanation

    RoPE and earlier positional encoding

    Earlier absolute position methods attach a position signal to each token before attention. Fixed sinusoidal PE is useful because it gives every position a wave pattern.

    Sinusoidal PE

    Position is added to the token vector.

    x = token + PE(position)

    Attention still has to learn how those absolute tags imply distance.

    RoPE

    Position rotates query and key pairs.

    q' dot k' = f(q, k, m - n)

    The relative gap appears directly in the attention score.

    RoPE preserves vector length because rotation does not stretch the vector. Standard RoPE also adds no learned parameters. Very long context still needs care, so RoPE is not unlimited context by itself.
